MC Beats

MC Beats is a live procedural synthesizer for drums, bass, chords, and lead. It creates sound in the browser from oscillators and procedural noise, with no recorded samples.

The app supports live playing from the keyboard and on-screen controls, four-bar recording on two decks, deck switching and transfer, solos, sound presets, and agent control through WebMCP in a compatible browser. An agent can build patterns, schedule musical changes, and play alongside a person.

Run the app locally with the project's development command, then open the local address shown by the server. Start audio from the app before playing. The normal engine uses the independent voice system; add ?synth=legacy to the URL to use the preserved legacy engine for comparison or rollback.

The project is a React and TypeScript application built with Vite. It is released under the MIT License.
